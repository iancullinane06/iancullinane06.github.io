# Notes and documentation

This GitHub Pages site contains [thermodynamics lecture notes](Thermo_notes/) and
the [LabPlotLib documentation](docs/). The homepage links to both.

The site is built with Jekyll and the GitHub Pages theme configured in
`_config.yml`. Lecture Markdown lives in `Thermo_notes/`, shared figures in
`Figures/`, and LabPlotLib reference pages and examples in `docs/` and
`examples/`. Add YAML front matter and a `title` and `nav_order` to new
documentation pages so they appear in the sidebar and search index. Each
example has a Markdown page with `title` and `nav_order`, and includes its
Python source with `include_relative` so displayed and downloadable code stay
in sync. Plot previews are generated by running their corresponding examples.
